# 公開識別子の検査

`internal/dev/apilist/apilist.go:1` は Go 標準の parser・go/ast を使い、依存をロードせずに宣言済みの公開識別子を列挙します。新しい外部依存はありません。`api/api_test.go:1` が現在の結果と `api/public.txt` を照合します。

対象は import できるパッケージ、公開された型・関数・メソッド・変数・定数、型の公開フィールド・interface のメソッド・公開型の埋込み名です。非公開型も返り値などを通じて利用され得るため、その公開メンバーは保守的に列挙します。`internal/`、`cmd/`、`examples/`、`testdata/`、vendor、隠しディレクトリ、Go が無視する `_` 接頭辞のディレクトリ、検査自身の `api/`、テストファイル、main package、入れ子の別モジュールは除外します。`x/` は列挙しますが、互換性の約束には含めません。

OS・build tag の制約を評価せず、各 Go ファイルの宣言の和集合を取ります。同名の宣言はまとめ、順序を固定して LF で保存します。Windows の checkout で CRLF になった一覧もテストで正規化します。ソースが解析できない場合はファイル名を含むエラーにします。

```sh
go test ./api -count=1
go run ./internal/dev/apigen
go test ./api -count=1
```

更新コマンドは本体モジュールのルートで実行します。最初の検査で増減を見た後、利用者・目的・契約を確認してから更新し、差分をレビューします。T2 の一覧には中核 API の宣言と、公開エイリアス経由で使えるメンバーを含めます。

同じモジュール内の型エイリアスは宣言先まで辿り、直接宣言された公開フィールド・メソッドを公開名の下へ列挙します。参照先が `internal/` でも対象です。内部の型そのものを独立した公開 API として列挙するわけではありません。外部モジュールのエイリアスと promoted method は展開しません。

この検査は名前の増減の可視化です。シグネチャ、定数値、型の互換性、非公開型や埋込みによる promoted method、動作の意味、build tag の組合せの成立を保証しません。API の互換性には godoc・利用例・契約テストとレビューを併用します。制作支援は `cmd/`・`internal/` に収め、公開 API を追加しません。
