# 表示サンプルの素材台帳

`examples/play` の名称・台詞・地図・画像生成コードは、このリポジトリのために新規作成した一般向けの例です。背景・敵・人物は `examples/play/art.go` の図形で描きます。画像・音声・台詞を他の作品から取り込んでいません。新規部分にはリポジトリの MIT ライセンスを適用します。

Go Regular フォントは `golang.org/x/image v0.45.0/font/gofont/goregular` から読み込みます。作者・出典・配布時に添付する BSD 通知、画像と GIF の生成方法は [ASSETS.md](../../ASSETS.md) にまとめました。サンプルの実行と撮影は [Wayfinder](wayfinder.md) を参照してください。
