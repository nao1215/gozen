# 表示サンプルの素材台帳

`examples/play` の名称・台詞・地図・絵は、このリポジトリのために新規作成した一般向けの例です。画像・音声・台詞を他の作品から取り込んでいません。コードと文面は MIT、絵は CC BY 4.0（`examples/play/game/assets/LICENSE`）です。Go Regular フォントの通知は [ASSETS.md](../../ASSETS.md) にあります。サンプルの実行と撮影は [Wayfinder](wayfinder.md) を参照してください。

`assets/walker/eyes_closed.png`・`mouth_open.png` は Walker の会話の立ち絵を動かす差分（目を閉じた所・口を開けた所）で、ほかの絵と同じ CC BY 4.0 です。置き方は `assets/walker/puppet.yaml`（[動く立ち絵](../architecture/puppet.md)）。
