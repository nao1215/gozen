# Asset ledger for the CLI fixtures

The YAML, names and text in `e2e/atago/fixtures/game` are a general-audience camp exploration created new for T4. `assets/mote.png` is an 8x8 single-color marker drawn in code, under Gozen's MIT license.

The RPG starter under `cmd/internal/starter/templates/rpg/assets` reuses this original `mote.png`. The campaign starter's `valley.png` is generated by `valley` in `cmd/internal/starter/starter.go`; it is original placeholder artwork under the same MIT license. Starter text and YAML are also original MIT-licensed Gozen material.

`e2e/atago/fixtures/puppet` is a neutral set of shapes created new to test `gozen art puppet` (a gray body, a round head, an eye band, a red mouth shape), under Gozen's MIT license. The source for regenerating it is [puppet-fixtures.go.txt](puppet-fixtures.go.txt) (used the same way as described below).

The source for regenerating is [cli-fixtures.go.txt](cli-fixtures.go.txt). At the repository root, copy it to a temporary directory with the extension `.go` and run `go run <temporary file>`; it rewrites this fixture's PNGs and font. The output goes only to the fixed fixtures inside the repository.

`assets/regular.ttf` is the Go Regular font from `golang.org/x/image/font/gofont/goregular` (the version in go.mod), copied unchanged. The authors are Bigelow & Holmes; the source is [Go fonts](https://go.googlesource.com/image/+/refs/tags/v0.45.0/font/gofont/ttfs/README). The following notice is provided with the public fixture.
