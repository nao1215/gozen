# ADR 0012: 汎用 CLI の所有権と出力先

状態: 採用。対応: T4、D2、D8、D10。入口は [ADR 0016](0016-single-cli.md) で変更しました。`cmd/rpgcheck`・`cmd/rpgtool` は `cmd/gozen` の 1 本に、`cmd/rpgtool/internal` は `cmd/gozen/internal` になりました。以下は採用時の記録で、出力・終了値・上書き防止の規約は `gozen` の全サブコマンドに引き継ぎます。

## 問題

汎用 CLI は検査だけでなく、シミュレーション、文書化、部分配布、撮影を組み立てます。補助処理をすべて公開パッケージにすると利用者のいない API が増え、出力先の再作成を踏襲すると既存の作業を消すおそれがあります。

## 決定

`cmd/rpgcheck` と `cmd/rpgtool` がプロセス終了を所有します。共通の引数、出力、保存先検証は `cmd/internal/cli`、描画しない構造検査は `cmd/internal/checkdata`、部分配布の解析は `cmd/internal/trial` に置きます。戦闘曲線と設計評価は今回 CLI だけが使うため `cmd/rpgtool/internal/balance`・`designeval` に置き、`x/` の公開パッケージを増やしません。

これらは全て既存の入口 component に属します。`.go-arch-lint.yml` に共有 `cmd/internal/**` の所属を明記します。下位のライブラリからコマンドへの依存や層の例外は追加しません。フォントと表示規則の利用は表示層の既存 internal を通します。

全サブコマンドの help は画面・音・外部コマンドを起動せず成功させます。結果は stdout、警告・進捗・診断は stderr。終了値は成功と help が 0、I/O・検査・シミュレーション・撮影の失敗が 1、引数形式の不正が 2。書込みと Close の失敗も成功に変えません。

生成ディレクトリは新規の場所に限定します。既存ファイル、空ディレクトリ、シンボリックリンクも上書きしません。入力との包含関係は既存部分のシンボリックリンクとファイル同一性を考慮して検査し、ファイルシステム内のパスと OS パスを区別します。trial と release、メモの HTML は専用の作業木から新規出力へ確定します。trial の dry run は `-list` があっても何も書きません。

設計評価は Git の実行や制作環境の情報収集を行いません。メモ出力は明示指定時だけです。報酬の種類は設定から取り、撮影の分類は一般的な人物・段階・構図とします。撮影の承認待ちは終了値 1 にし、失敗ログを stdout/stderr 別のファイルへ残します。

## 代案と結果

実験パッケージとして公開する代案は、CLI 以外の具体的な利用者が現れるまで見送ります。汎用化のための設定は維持しますが、作品の設定や既存の fixture は持ち込みません。公開 API の一覧に変更はありません。

出力名の安全性と上書き防止は利用者の誤操作への保護です。敵対的な別プロセスによる親ディレクトリの同時差し替えまで保証するトランザクションではありません。Windows・macOS の実行確認は各 OS の CI として配線し、クロスビルドと区別します。
