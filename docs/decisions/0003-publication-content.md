# ADR 0003: 公開内容と検査データ

状態: 採用。日付: 2026-10-18。対応: D3。

## 背景

公開ライブラリでは、コードの依存を分けるだけでなく、コメント、既定値、テスト、生成物も公開に適した内容である必要があります。

## 決定

fixture と golden は一般向けのオリジナルの例で作り、テストデータの組立ては `internal/testgame/` に置きます。作品固有の設定や私的な制作記録を既定値にしません。

Gozen 内の漏れの検査は、個人環境の絶対パスや私的なホスト名など一般的な形式を対象とします。内容の照合はリポジトリ外の非公開の一覧で別に行います。

## 理由

検査データや検査用の一覧自体から非公開情報が公開されるのを防ぎ、特定の制作環境なしで検査を再現できるようにします。

## 結果

単語検索に加えて意味と文脈を読み、コメント・設定・テスト・サンプル・素材・埋込み・生成物・バイナリの文字列も確認します。公開前の手順は [リリース点検](../development/release-checklist.md) にまとめます。
