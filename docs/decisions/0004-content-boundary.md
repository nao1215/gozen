# ADR 0004: 本体と制作支援の境界

状態: 採用。日付: 2026-10-18。対応: D4、D10。配置の変更は [ADR 0009](0009-single-module.md) を参照。

## 背景

公開ライブラリと、用途の異なる制作支援では扱う機能が異なります。依存の分離だけでは、公開する内容の分離を保証できません。

## 決定

ライブラリと汎用 CLI は一般向けの汎用機能だけを提供します。非公開の作品データや制作情報を、コメントや識別子を含めて入れません。

`internal/promptgen`・`internal/mosaic` とそれぞれの配下（`gozen prompt`・`gozen mosaic` の実装である `command` パッケージを含む）に限り、作者が許可した制作用途の機能を扱えます。サンプル・既定値・テストも公開できるオリジナルの内容にします。検出の分類や制約は、ツールの公開仕様として独立に説明できるものにします。ONNX モデルは同梱せず利用者に指定してもらいます。`cmd/gozen` は振り分けと中立な一覧の help だけを持ち、汎用に保ちます（[ADR 0016](0016-single-cli.md)）。

## 理由

ライブラリ利用時に制作支援のパッケージをビルドする必要はありません。制作ツールも、特定の作品の秘密の設定なしに利用・検査できる形にします。

## 結果

上記の配置とその他を別の基準で内容確認し、固有情報を含めない条件はすべてに適用します。モジュール全体を制作支援の扱いにはしません。モデル・サンプル・生成物の出自も確認対象です。公開する例は専用に作成します。
