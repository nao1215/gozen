# ADR 0005: 新規のサンプルと素材

状態: 採用。日付: 2026-10-18。対応: D5。

## 背景

ライブラリの利用例と画面の紹介には、公開できる素材と再現可能な操作が必要です。権利と出所を説明できる専用の例を用意します。

## 決定

`examples/` に移動・会話・イベント・戦闘・保存を試せる一般向けの小さなオリジナルゲームを作ります。素材はコードで描く図形・ドット絵、または出所とライセンスを記録した CC0 等を使います。画像・音・シナリオ・紹介画像も同じ基準で用意します。

紹介用の GIF とスクリーンショットは、そのサンプルを Linux の Xvfb 上で動かして撮ります。CLI のデモにも専用の中立素材を作り、`gozen mosaic` は合成画像、`gozen prompt` は新規の中立 catalog を使います。

## 理由

利用例を公開 API の実際の利用者にし、権利と内容の確認を再現できるようにします。スクリーンショットを描画検査の成功の代わりにはしません。

## 結果

素材の出所・ライセンス・生成方法をサンプルの文書に残します。第三者素材の出典とライセンスは `ASSETS.md` にまとめます。

## 追記（2026-10-19）

Wayfinder の絵はコードで描く図形から生成画像に替えました。絵のライセンスはコードと分け、コードは MIT、サンプルの絵は CC BY 4.0 とします（`examples/play/game/assets/LICENSE`）。絵の作り方は公開物に記録しません。
