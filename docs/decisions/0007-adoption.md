# ADR 0007: 公開 API によるゲームの組込み

状態: 採用。日付: 2026-10-18。対応: D7。

## 背景

ゲーム作者が公開 API だけでゲームを組み立てられることを確認する必要があります。内部実装に依存する利用例では公開境界の検証になりません。

## 決定

起動、データ検証、状態遷移、保存と復元、描画・音の接続を、ゲーム側から公開 API だけで組み立てられることを設計の条件とします。作品固有のデータ・表現・拡張はゲーム側が所有し、Gozen には汎用の小さな拡張点を設けます。

## 理由

実際の利用例で公開境界の不足を発見しながら、特定の作品の仕様をライブラリの既定にすることを避けます。

## 結果

`examples/` を公開 API の利用者として契約を検査します。不足を発見した場合は API を増やす前に責務と小さな拡張点を見直します。画面・音声・OS ごとの実行は、描画なしのテストやクロスビルドとは別に確認します。
