# Five Banners assets

Five Banners is a stage 0 prototype of a region-conquest strategy game. Its Go code and YAML
(`main.go`, the tests, `game/game.yaml`, `game/data/`) are MIT like the rest of the
repository. It draws nothing new: every file under `game/assets/` is a copy of a Go Zen asset
(`examples/go-zen/game/assets/`), listed in [Go Zen's ASSETS.md](../go-zen/ASSETS.md).

| `maren/`, `ox/`, `tilly/`, `kes/` | The whole-figure picture of each face (`normal.png`) | CC BY 4.0 |
